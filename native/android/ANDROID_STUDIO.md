# MATCHLAB AZ — Android Studio
Exported via GitHub Actions as self-contained Android Studio project and debug APK.
Android Studio: File > Open > MATCHLAB_AZ_Android_Studio.
Build > Build Bundle(s) / APK(s) > Build APK(s).
Gradle 8.9, Android Gradle Plugin 8.7.3, JDK 17, compile SDK 35.
The archive includes a Gradle wrapper, bundled HTML/JS/CSS, native Java source and app icons.
