# MATCHLAB AZ 0.9.46 — Native Android / Android Studio

This branch replaces the WebView user interface with native Java Android screens:
Live matches, standings, worldwide identity search, profiles, favourites,
match-detail events and statistics, and a canvas-drawn tactics pitch.
No HTML, CSS, JavaScript, or WebView resources are bundled into the APK.

The desktop HTML/EXE remains a separate product and is unchanged.
Backend requests use the existing HTTPS Render API. No synthetic real match results.

## Android Studio

Download the native source ZIP generated by the Android Studio GitHub Actions
workflow. Extract its root folder, open it in Android Studio using File > Open,
wait for Gradle Sync, and select Build > Build APK(s).
JDK 17, Android Gradle Plugin 8.7.3, Gradle 8.9, Android SDK 35.
Debug APK version code 946. Release signing needs a stable private keystore.

## Data & feature limits

- This is the native Android baseline, not pixel-perfect parity with the HTML app.
- API availability and completeness depend on the live server and legal sources.
- The tactics pitch shows a numbered formation diagram, not verified football lineups.
- Native notifications and advanced interactive tactic editing remain future work.
- Android does not guarantee that two differently signed debug APKs can update each other.
  Back up local saved favourites/preferences before considering removal.

## Verification

CI checks Java compilation, Android launcher label, absence of embedded HTML/browser
assets and launches the app in a Pixel emulator. This does not replace physical
HyperOS/Redmi device testing.
