# MATCHLAB AZ v0.9.54 — Windows Premium + Android TEST

## Fayllar
- **MATCHLAB_AZ_Setup_0.9.54_x64.exe** — Windows 10/11 x64 quraşdırıcısı; Start menyusu, seçimlə masaüstü qısayolu, silinmə dəstəyi
- **MATCHLAB_AZ_Portable_0.9.54_x64.exe** — .NET 8 daxil olan quraşdırmasız Windows EXE
- **MATCHLAB_AZ_Android_0.9.52_TEST.apk** — mövcud Android debug/test APK-sı, **bu buraxılışda Android kodu dəyişdirilməyib**

## Windows yenilikləri
- Ekran ölçüsünə uyğun dashboard düymələri, daha oxunaqlı ana ekran
- Liqa üzrə qruplaşdırma və açılıb-bağlanan matç siyahıları
- Hamısı, canlı və seçilmiş oyunlar filtrləri
- Azərbaycan Premyer Liqası daxil əlavə liqa seçimləri
- Şəxsi taktika üçün oxların animasiyalı vizual göstərilməsi və PNG ixracı
- Mövcud v0.9.53 imkanları: əvvəlki M loqosu, qısa native açılış animasiyası, klub emblemləri (mövcud mənbədə), lokal keş, heyətlər, statistika, oyunçu profilləri
