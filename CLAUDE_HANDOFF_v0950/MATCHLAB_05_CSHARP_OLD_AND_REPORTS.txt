# MATCHLAB AZ Native Windows — v0.9.47

Bu, əvvəlki 0.9.46 proqramının daha dolğun, saytdakı üsluba yaxınlaşdırılmış **.NET Windows Forms** versiyasıdır. **HTML, JavaScript və WebView istifadə olunmur.** Proqram öz lokal pəncərəsində açılır və başlanğıc animasiyası ilə çərçivəsiz tam ekran rejimini saxlayır.

## Ən sadə quraşdırma

1. ZIP faylına sağ bas → **Tümünü Ayıkla / Extract All**.
2. Çıxarılan qovluqdakı **TEK_TIKLA_KUR.cmd** faylına iki dəfə bas.
3. Build testi keçərsə, proqram masaüstünə və Başlat menyusuna əlavə ediləcək və özü açılacaq. Sonrakı açılışlar üçün yalnız **MATCHLAB AZ** ikonuna bas.

Kompüterində .NET 8 SDK artıq quraşdırılıbsa, yenidən SDK yükləmək lazım deyil. Kodun build mərhələsi şəbəkə üzərindən NuGet və ya Windows SDK paketlərinə ehtiyac duya bilər. İstifadəçi bir dəfə proqramı kompilyasiya etməlidir: bu ZIP-in içində hazır Windows EXE yoxdur.

**Inno Setup 6** varsa, skript normal Setup.exe yaradıb işə salır: həm masaüstü/Start qısayolları, həm də Windows Installed Apps və uninstall imkanı yaranır. Inno Setup yoxdursa, skript tətbiqi `%LOCALAPPDATA%\Programs\MATCHLAB AZ\` qovluğuna kopyalayır və masaüstü/Start qısayollarını yaradır. Bu sadə ehtiyat variantı Installed Apps siyahısına qeyd yazmır.

## Görünüş və funksiyalar

- Tünd göy, yaşıl və firuzəyi vizual dil: daha dolu ana səhifə, hero, statistik kartlar, futbol matçları önizləməsi, sürətli keçidlər
- Sidebar başlığında daha oxunaqlı MATCHLAB AZ loqosu və tam menyu adları
- Axtarış üçün başlıq sahəsi; server gec açılarkən 211 yerli kəşf qeydi göstərilə bilər (tam 506 207 rekord deyil)
- Canlı matçlar, turnir cədvəli, profil axtarışı, seçilmiş matçlar və taktika lövhəsi
- Açılış animasiyası, avtomatik tam ekran, F11 ilə rejim dəyişikliyi, Esc ilə adi pəncərəyə qayıtmaq
- Şəbəkə yoxlaması indi açılışı bloklamır; serverin oyanması saniyələrlə statusda görünür; nəticə alınmayanda xəta və yenidən yoxlama təqdim olunur
- Canlı nəticələr **uydurulmur**; server real mənbə cavabını təsdiqləmirsə, bu açıq göstərilir.

## Serverin gec oyanması

Render-in **pulsuz planı** 15 dəqiqə fəaliyyətsizlikdən sonra yuxu rejiminə keçə bilər. Bu, bəzən təxminən 1 dəqiqəlik açılış gecikməsi deməkdir. Masaüstü tətbiq bu məhdudiyyəti aradan qaldıra bilmir. Kod UI-ni aktiv saxlayır, server statusu üçün daha uzun müddət gözləyir, xətanı aydınlaşdırır. Daima sürətli bağlantı üçün yuxu rejimi olmayan hosting lazım ola bilər.

## Test və hazırda məhdudiyyət

- Python ilə mənbə paketinin əsas faylları, konfiqurasiya, JSON indeksinin düzgünlüyü, eyni adlı köməkçi metod/field toqquşmalarının olmaması statik yoxlanılır.
- **Bu mühitdə .NET SDK və Windows olmadığı üçün yeni EXE kompilyasiyası və WinForms ekran testi burada icra edilməyib.** `TEK_TIKLA_KUR.cmd` build nəticəsini və proqramın `--ui-smoke-test` çıxış kodunu yoxlayır; uğursuz olarsa yeni quraşdırma etmir.
- İmzasız EXE/installer Windows Defender SmartScreen tərəfindən xəbərdar edilə bilər. Təhlükəsizlik proqramını söndürmək tövsiyə olunmur. İmza/Store yayımı ayrıca məsələdir.

    // Starts in fullscreen. F11 toggles fullscreen; Esc exits to framed maximized.
    // Keep the desktop taskbar and normal window controls accessible after exit.
    private void ToggleImmersive()
    {
        if(!immersive)
        {
            previousWindowState=WindowState;
            previousBounds=WindowState==FormWindowState.Normal?Bounds:RestoreBounds;
            FormBorderStyle=FormBorderStyle.None;
            WindowState=FormWindowState.Normal;
            Bounds=Screen.FromControl(this).Bounds;
            WindowState=FormWindowState.Maximized;
            immersive=true;
        }
        else
        {
            WindowState=FormWindowState.Normal;
            FormBorderStyle=FormBorderStyle.Sizable;
            if(previousBounds.Width>0 && previousBounds.Height>0)
                Bounds=previousBounds;
            WindowState=previousWindowState;
            immersive=false;
        }
    }

    private async Task CheckServerAsync()
    {
        if(probing)
        {
            connectionDetail="Serverə sorğu göndərilib və cavab gözlənilir. Cari proses davam edir.";
            HomeRefreshStatus();return;
        }
        probing=true;probeStarted=DateTime.UtcNow;
        reconnect.Text="↻ Qoşulur...";reconnect.Enabled=false;
        serverLabel.ForeColor=Orange;serverLabel.Text="● Qoşulur";
        connectionDetail="Serverə qoşulur… Pulsuz Render hosting yuxu rejimindən oyanırsa, bu təxminən 1 dəqiqə çəkə bilər.";
        probeClock.Start();HomeRefreshStatus();
        try
        {
            var data=await Get("/api/status",105000);
            connected=ReadBool(data,"ok")||ReadBool(data,"backend");
            var total=Property(Property(data,"world"),"total");
            if(total.ValueKind==JsonValueKind.Number&&total.TryGetInt32(out var n)&&n>0)serverTotal=n;
            serverLabel.ForeColor=connected?Green:Error;
            serverLabel.Text=connected?"● Server aktiv":"● Cavab natamam";
            connectionDetail=connected?"Serverə HTTPS bağlantısı quruldu. Arxiv və matç məlumatları mənbədən yoxlanır.":
                "Server status cavabında təsdiq tapılmadı. Digər bölmələr lokal işləyir.";
        }
        catch(OperationCanceledException)
        {
            connected=false;serverLabel.ForeColor=Error;serverLabel.Text="● Vaxt bitdi";
            connectionDetail="Server 105 saniyədə cavab vermədi. İnternetini və Render hosting statusunu yoxla.";
        }
        catch(HttpRequestException ex)
        {
            connected=false;serverLabel.ForeColor=Error;serverLabel.Text="● Bağlantı xətası";
            connectionDetail="Server bağlantısı alınmadı: "+ex.Message;
        }
        catch(Exception ex)
        {
            connected=false;serverLabel.ForeColor=Error;serverLabel.Text="● Mənbə əlçatan deyil";
            connectionDetail="Server sorğusu nəticəsiz qaldı: "+ex.Message;
        }
        finally
        {
            probeClock.Stop();probing=false;reconnect.Enabled=true;reconnect.Text="↻ Yenidən yoxla";
            HomeRefreshStatus();
        }
    }
    private void HomeRefreshStatus()

        }

        if(homeServerLabel!=null&&!homeServerLabel.IsDisposed)
            homeServerLabel.Text=connected?"Aktiv":probing?"Oyadılır":"Xəta";
    }
    private static JsonElement Property(JsonElement e,string key)
        =>e.ValueKind==JsonValueKind.Object&&e.TryGetProperty(key,out var value)?value:default;
    private static string Str(JsonElement e,string key,string fallback="")
    {
        var v=Property(e,key);
        return v.ValueKind switch
        {
            JsonValueKind.String=>v.GetString()??fallback,
            JsonValueKind.Number=>v.ToString(),
            JsonValueKind.True=>"true",
            JsonValueKind.False=>"false",
            _=>fallback
        };
    }
    private static bool ReadBool(JsonElement e,string key)=>Property(e,key).ValueKind==JsonValueKind.True;
    private static IEnumerable<JsonElement> Items(JsonElement e,string key)
    {
        var v=Property(e,key);
        return v.ValueKind==JsonValueKind.Array?v.EnumerateArray():Enumerable.Empty<JsonElement>();
    }
    private static async Task<JsonElement> Get(string path, int milliseconds=92000)
    {
        using var cancel=new CancellationTokenSource(milliseconds);
        using var response=await Api.GetAsync(path,cancel.Token);
        response.EnsureSuccessStatusCode();
        await using var stream=await response.Content.ReadAsStreamAsync(cancel.Token);
        using var doc=await JsonDocument.ParseAsync(stream,cancellationToken:cancel.Token);
        return doc.RootElement.Clone();
    }

    public static void FillRoundedRectangleSafe(this Graphics g,SolidBrush brush,RectangleF rect,float radius)
    {
        using var path=new GraphicsPath();

        path.AddArc(rect.Right-d,rect.Top,d,d,270,90);

        path.AddArc(rect.Left,rect.Bottom-d,d,d,90,90);
        path.CloseFigure();
        g.FillPath(brush,path);
