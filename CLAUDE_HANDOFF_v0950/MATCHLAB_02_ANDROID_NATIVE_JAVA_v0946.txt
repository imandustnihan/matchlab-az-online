# MATCHLAB AZ v0.9.46 — Windows EXE + Android APK mənbələri

Bu ZIP **hazır EXE/APK deyil**. Windows (.NET 8 WinForms) və Android (Java) üçün işlək paket yaratmağa hesablanmış mənbə kodu, build workflow-ları və Windows quraşdırıcısıdır. Hazırkı söhbətdə Windows .NET SDK, Android SDK və GitHub-a push hüququ olmadığı üçün kompilyasiya və cihaz sınağı təsdiqlənməyib.

## Windows (əvvəl)
- `native/windows-app/Program.cs`: HTML və WebView2 olmadan Windows Forms interfeysi, lokal taktika, matçlar və axtarış, HTTPS API.
- `native/windows-app/StartupSplash.cs`: təxminən 2 saniyəlik **doğma GDI+ açılış animasiyası**; yüklənmə faizi uydurulmur.
- İlk çərçivədən etibarən **çərçivəsiz tam ekran**. `Esc` normal pəncərəyə, `F11` tam ekrana keçid edir.
- `native/windows-installer/installer.iss`: quraşdırılan tətbiq, Başlat menyusu, masaüstü qısayolu və normal silmə.
- `BUILD_WINDOWS.cmd`: Windows 11-də .NET 8 SDK quraşdırılıbsa EXE-ni lokal kompilyasiya edir. Inno Setup 6 quraşdırılıbsa Setup yaratmağa da çalışır.
- GitHub Actions workflow: `.github/workflows/matchlab_build_native_windows_v0946.yml`.

## Android (sonra)
- `native/android/app/src/main/java/az/matchlab/mobile/MainActivity.java`: tam Java **native** interfeys, HTML və WebView yoxdur.
- `NativeSplashView.java`: telefon tam ekranda açılan kimi loqo, hərəkətli yaşıl halqa, tətbiq adı və animasiya.
- **Sistem status və naviqasiya çubuqları gizlənir**; kənardan sürüşdürməklə müvəqqəti görünə bilər. Gesture sahəsi üçün alt hissədə qoruyucu boşluq var.
- 6 alt menyu, canlı matçlar, turnir cədvəli, axtarış, profil, matç detalları, favoritlər, taktika lövhəsi, server vəziyyəti.
- Backend cavab verməsə, heç bir qondarma statistika göstərilmir. Lokal menyular və taktika açılır.
- `.github/workflows/matchlab_native_android_v0946.yml` — Android emulator, splash, açılış, APK və Android loqo yoxlamaları.

## GitHub-da real EXE və APK alınması
1. Mövcud `imandustnihan/matchlab-az-online` repository-ni klonla və **ayrıca branch** aç: `fix/native-windows-android-v0946`.
2. ZIP-in içindəki `native/windows-app/`, `native/windows-installer/`, `native/android/` və `.github/workflows/` qovluqlarını eyni yollara əlavə et. Köhnə başqa faylları silmə.
3. Dəyişiklikləri commit və push et.
4. GitHub **Actions** bölməsində `MATCHLAB AZ — Real Native Windows Build v0.9.46` və `MATCHLAB AZ - Android Native Fullscreen & Splash v0.9.46` workflow-larını işlə.
5. Hər ikisi **Success** göstərdikdən sonra **Artifacts** bölməsindən `MATCHLAB_AZ_Real_Native_Setup_v0946` və `MATCHLAB_AZ_Android_Native_APK_v0946` ZIP paketlərini endir. Quraşdırıcı həqiqi `MATCHLAB_AZ_Native_Setup_v0946.exe`, Android `app-debug.apk` saxlayacaq.

### İmza və təhlükəsizlik
- Windows Setup **rəqəmsal imzalanmayıb**. SmartScreen xəbərdarlığı ola bilər. Təhlükəsizlik qorumasını söndürmə.
- Android APK debug imzalıdır. Google Play üçün release signing, fərqli Play Store siyasətləri və istifadəçi cihazında test tələb olunur.
